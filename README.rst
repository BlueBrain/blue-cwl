blue-cwl
========

Common Workflow Language tool/workflow definitions, wrappers, and API

Documentation
=============

* `latest <https://blue-cwl.readthedocs.io/en/latest/>`_

Installation
============

blue-cwl can be pip installed with the following command:

.. code-block:: bash

    $ pip install blue-cwl

Tests
=====

.. code-block:: bash

    pip install tox
    tox
